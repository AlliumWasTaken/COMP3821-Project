Overview

Introduced by David Karger in 1993, Karger’s Min Cut Algorithm solves the global minimum cut problem on undirected multigraphs using randomized edge contractions [2].

While deterministic algorithms execute a completely determined sequence of states yielding the exact same output for an input, randomized algorithms incorporate random choices governed by a probability distribution. This prevents adversaries from constructing worst-case inputs and often results in substantially simpler algorithms.

Randomized algorithms are broadly categorized into two groups [3]:

Category Las Vegas Algorithms Monte Carlo Algorithms
Correctness Guaranteed Uncertain (Bounded failure rate)
Running Time Uncertain (Random variable) Guaranteed (Deterministic bound)
Example Randomized QuickSort Karger's Min Cut, Miller-Rabin

Karger’s algorithm is a Monte Carlo algorithm: its execution time is fixed and strictly bounded, but each single trial has a small probability of returning a sub-optimal cut.

Intuition

Consider a graph whose minimum cut has size k. By definition, exactly k edges cross this cut, while the total number of edges in the graph is typically much larger (at least nk/2).

If an edge is selected uniformly at random, the odds of picking one of the k critical cut edges are relatively low (at most 2/n in the first step). The algorithm is statistically more likely to contract an edge located safely inside one of the partitions. Repeating contractions until only two super-nodes remain yields a non-trivial probability that the true minimum cut was never contracted.

Pseudocode

Given an undirected multigraph G = (V, E) with |V| = n:

  1. While |V| > 2:
    1. Choose an edge e = {u, v} ∈ E uniformly at random.
    2. Contract e to form G / e (merge endpoints, remove self-loops, keep parallel edges).
  2. Return the cut defined by the two remaining composite vertices.

Proof of Correctness

Let C* be a global minimum cut with capacity k = |C*|.

Lemma (Lower Bound on Number of Edges): For each vertex v ∈ V, the cut separating {v} from V \ {v} has size deg(v) ≥ k. Summing degrees:
2|E| = ∑ deg(v) ≥ nk &implies; |E| ≥ nk / 2.

Step 1: The probability that the first contracted edge belongs to C* is:
P(e1 ∈ C*) = |C*| / |E| ≤ k / (nk/2) = 2/n.
Thus, P(survives step 1) ≥ 1 − 2/n = (n − 2) / n.

Step i: If no edge of C* has been contracted in the first i − 1 steps, the remaining graph has n − i + 1 vertices and its minimum cut size remains at least k. The conditional probability of contracting an edge in C* is at most 2 / (n − i + 1).

Telescoping Product: The probability that C* survives all n − 2 contractions is:

P(Success) ≥ ((n - 2) / n) × ((n - 3) / (n - 1)) × ... × (2 / 4) × (1 / 3) = 2 / (n(n - 1)) = 1 / &binom;{n}{2}.

Remark on Weighted Graphs: The exact same proof holds for graphs with non-negative real edge weights by sampling edges with probability proportional to their weight, p(e) = w(e) / ∑ w(e').

Probability of Success

A single execution succeeds with probability at least p ≥ 2 / (n(n − 1)) = Ω(1 / n2).

While O(1/n2) is small, running T independent repetitions and tracking the minimum cut found amplifies the success rate. The probability that all T trials fail is:

P(All fail) ≤ (1 - 2/n2)T ≤ e-2T / n2

Setting T = Θ(n2 ln n) guarantees that the global minimum cut is found with high probability (failure probability ≤ 1/n).

Time and Space Complexity

  • Single Run: Using a Disjoint-Set Union (Union-Find) data structure or adjacency list relabeling, a single contraction phase runs in O(m α(n)) or O(n2) time.
  • Amplified Algorithm: Performing O(n2 ln n) independent runs leads to an overall time complexity of O(n4 ln n) on dense graphs.
  • Space Complexity: O(n + m) to store the vertices, edge list, and disjoint-set parent pointers.

For an optimized variant, see the Karger-Stein algorithm, which uses recursive contraction to achieve an improved O(n2 log3 n) runtime.
