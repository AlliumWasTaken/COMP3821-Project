Summary

There are often many different types of algorithms to solve the same problem, and one such dichotomy is between deterministic and randomised algorithms. In this case, when finding the global minimum cut of an undirected, graph, we can compare the deterministic Stoer-Wagner [6] and the randomised Karger’s algorithm (Amplified Karger's algorithm meaning rerunning the algorithm multiple times to improve accuracy). We will additionally compare them to Karger–Stein, a more optimised and efficient, yet still randomised, algorithm to demonstrate the relative strengths of randomised algorithms.

Generally, deterministic algorithms execute a fixed sequence of steps that guarantee exact, reproducible results for any input, while randomised algorithms introduce random decision making. Randomised algorithms can either trade guaranteed runtime for exactness (Las Vegas algorithms) or can exchange guaranteed exactness for a simpler, bounded runtime (Monte Carlo algorithms) [3].

Time Complexity

The running times of these algorithms depend heavily on graph density (sparse graphs where m = Θ(n) versus dense graphs where m = Θ(n2)):

  • Stoer–Wagner: Stoer–Wagner runs n − 1 minimum-cut steps. Using a Fibonacci heap for Maximum Adjacency Search, each phase takes O(m + n log n) time, alternatively O(n2) with an adjacency matrix [6]. This means that on sparse graphs it achieves a time complexity of O(n2 log n), however on dense graphs, it scales to O(n3).
  • Basic Karger (Amplified): A single contraction pass takes O(n2) time. However, because a single run succeeds with probability only Ω(1/n2), achieving high probability requires Θ(n2 ln n) repetitions, making basic Karger significantly slower than Stoer–Wagner with a time complexity of O(n4 log n) [9, 10].
  • Karger–Stein: By delaying branching until the graph shrinks to n/√2 vertices, Karger–Stein lowers the cost of a single run to O(n2 log n) while boosting success probability to Ω(1/log n) [2]. Amplifying with O(log2 n) repetitions achieves O(n2 log3 n), thus beating Stoer–Wagner on dense graphs (O(n2 log3 n) vs O(n3)).

It's worth noting that in empirical benchmarks, it has been observed that despite Karger–Stein's superior asymptotic bound on dense graphs, deterministic approaches like Stoer–Wagner (especially when paired with heuristic reductions) often run faster in practice on medium sized graphs [5].

Space Complexity

  • Stoer–Wagner: Stoer–Wagner operates in-place on a single copy of the graph. Using adjacency lists and a priority queue requires O(n + m) space, while an adjacency matrix implementation uses O(n2) space.
  • Basic Karger: Each run only tracks the current edge multiset and a Disjoint-Set Union structure. Because runs are independent, memory can be reused between trials, keeping total space at O(n + m).
  • Karger–Stein: Because Karger–Stein branches recursively into two independent subproblems on partially contracted graphs, it must store the intermediate graphs. Since vertex counts shrink geometrically (n, n/√2, n/2, …), it uses O(n2) space [2].

Correctness and Reliability

  • Stoer–Wagner: Stoer–Wagner uses a mathematical proof to guarantee that the last two vertices ordered by Maximum Adjacency Search always form a valid s–t minimum cut in the current graph [6]. Because no randomness is used, it executes the exact same steps every time and will always output the exact global minimum cut on every run.
  • Karger/Karger–Stein: Karger's algorithms do not guarantee an optimal result. Because every contraction preserves valid cuts, the algorithm can never return a cut smaller than the true minimum k, meaning any error is always an overestimation of k. Additionally, there is no fast way for a Monte Carlo algorithm to confirm that an answer is correct, with the fastest known certifier being a deterministic algorithm [11].

Another thing to note is that deterministic algorithms are completely reproducible, which makes them easier to debug and test but also means it is possible to intentionally construct worst case graphs that force maximum runtime. Conversely, randomised algorithms naturally avoid this due to their inherently non-deterministic nature [3].

Error Rate

  • Stoer–Wagner: The error rate is 0 since it never fails to find the exact minimum cut value.
  • Single-Run Karger: Fails with probability at most 1 − 2 / (n(n − 1)). For a 100-vertex graph, a single run has a ~99.98% chance of missing a specific minimum cut (worst case, such as a cycle graph Cn).
  • Amplified Karger and Karger–Stein: By repeating basic Karger C · C(n, 2) ln n times (or Karger–Stein c · log2 n times), the error rate reduces to at most 1 / nC [2, 10]. While this isn't technically perfect, choosing C = 3 on a graph with 1,000 vertices reduces the error probability to less than one in a billion, which in practice is usually lower than the probability of a hardware failure.

Real-World Applications

  • Network Reliability: Determining the fewest link failures required to disconnect a telecommunications network, power grid, or transit system [11]. In safety critical infrastructure where it is important to guarantee correctness, deterministic algorithms like Stoer–Wagner are strongly preferred over randomised methods.
  • Graph Clustering: Finding tightly knit clusters in social networks, biological protein-interaction graphs or hypertext document graphs [9, 11]. Karger’s algorithm naturally lends itself to clustering: instead of contracting down to 2 supernodes, the process can be halted at r supernodes to identify r natural communities.
  • Parallel Processing: When a system needs to identify all near minimum cuts, Stoer-Wagner cannot be easily parallelised and can only find one cut per run. Karger's algorithm naturally parallelizes much easier and is thus preferable to find all minimum cuts across independent trials [2, 11].

Conclusion

This comparison between Stoer–Wagner and Karger’s algorithms demonstrates why both deterministic and randomised algorithms are each useful in different situations, with their own strengths and weaknesses. You should choose the following when:

  • Stoer–Wagner: You are utilising sparse to moderately dense graphs, do not require parallelisation, require a 0% error guarantee and/or you need predictable, reproducible outputs without running any repetitions [5, 6].
  • Karger/Karger-Stein: You need a simple implementation, are utilising very dense graphs, are searching for multiple distinct minimum cuts and/or you want to utilise parallelisation [2, 9].

Karger’s algorithm proves that replacing a certain and deterministic algorithm with a randomised one can be the right choice in a variety of circumstances and that the error rate can be reduced arbitrarily close to zero through repetition, minimising the downside of their inherent uncertainty [3, 10].
